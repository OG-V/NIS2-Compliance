criticalAccess control and asset management

Admin console accepts admin/admin

Found

The admin console accepted the default username “admin” with its default password.

Should be

The default login is refused.

The rules require access control and that credentials are changed initially, i.e. before use. The scan logged into the admin console with the default username admin and password admin and was accepted. Default credentials are widely known, so anyone who can reach the console could take full administrative control. This requirement is not satisfied.

What to doQuick fix
  1. Change the password of the admin account on the admin console immediately so that admin/admin is rejected.
  2. Check whether the console was accessed with these credentials and treat the account as possibly compromised.
  3. Re-run the check to confirm the default login is no longer accepted.

highBusiness continuity and backups

Newest backup is 480 days old

Found

The newest backup was taken on 1 June 2025, 480 days ago.

Should be

A backup no older than 26 hours.

The rules require backup management and that backup copies of data are maintained. The scan found only one backup snapshot, and it is 480 days old, far beyond the maximum age the profile allows. If data were lost or corrupted today, almost everything changed since that snapshot could not be recovered, threatening business continuity.

What to doNeeds a change
  1. Restore regular, automated backup runs so that a new snapshot is produced within the maximum age set in the profile.
  2. Monitor backup jobs and alert when the newest snapshot becomes older than allowed.
  3. Test restoring from a recent snapshot to confirm the copies are usable.

Found

The server accepts password logins, which can be guessed or bypassed.

Should be

Only key-based logins (public key) are accepted.

The rules require authentication strength that matches the importance of the system. The SSH server offers password login alongside key-based login. Passwords can be guessed or reused from elsewhere, so offering them weakens remote access to the server.

What to doQuick fix

  2. Make sure keyboard-interactive and none are also not offered.
  3. Confirm all administrators have working keys before the change.

PermitRootLogin is 'yes'

Found

Anyone with the root password can log straight in as administrator (PermitRootLogin yes).

Should be

Direct root login is switched off. Administrators log in as themselves first.

The rules require administration privileges to be individualised and restricted. The SSH server allows direct login as root (PermitRootLogin is 'yes'). Root is a shared, all-powerful account, so logins cannot be traced to a person and an attacker gains full control in one step.

What to doQuick fix
  1. Set PermitRootLogin to 'no' in the SSH server configuration.
  2. Have administrators log in with personal accounts and elevate privileges only when needed.

The rules require policies on the use of cryptography and encryption. The server still accepts TLSv1 and TLSv1.1 in addition to TLSv1.2, while the profile sets TLSv1.2 as the minimum. Accepting older versions allows connections to fall back to weaker protection of data in transit.

What to doQuick fix

  2. Re-run the check to confirm only permitted versions are accepted.

Method and limits

  • Every verdict comes from deterministic, unit-tested checks. No language model is involved in any pass/fail decision.
  • Requirements are either hand-authored from NIS2 or extracted from CIR 2024/2690 by an LLM. Each one carries a verbatim quote that was verified against the official text and approved by a human reviewer.
  • Each check covers only part of the obligations it maps to, so the best possible verdict is partially evidenced.
  • Thresholds (log retention, backup age, password length and so on) come from the organisation's own profile, not from the law, which leaves them open.
  • Severity, effort, the actions and the "found / should be" lines are written by hand for each check and filled in from the scan's own values.
  • Narrative text is AI-drafted from this report's findings. It was accepted only after a validator confirmed that every gap is covered, every citation refers to a real failing finding, and no number or standard appears that is not in the data.
