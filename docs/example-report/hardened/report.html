Terms used in this report

NIS2
Directive (EU) 2022/2555, the EU law on cybersecurity for essential and important entities.
CIR 2024/2690
Commission Implementing Regulation (EU) 2024/2690, which sets out NIS2's technical measures in detail for digital service providers.
CSIRT
Computer Security Incident Response Team: the national body that significant incidents are reported to.
MFA, two-factor login

Method and limits

  • Every verdict comes from deterministic, unit-tested checks. No language model is involved in any pass/fail decision.
  • Requirements are either hand-authored from NIS2 or extracted from CIR 2024/2690 by an LLM. Each one carries a verbatim quote that was verified against the official text and approved by a human reviewer.
  • Each check covers only part of the obligations it maps to, so the best possible verdict is partially evidenced.
  • Thresholds (log retention, backup age, password length and so on) come from the organisation's own profile, not from the law, which leaves them open.
  • Severity, effort, the actions and the "found / should be" lines are written by hand for each check and filled in from the scan's own values.
  • Requirements without automated checks can be judged by a named reviewer from the organisation's documents. The reviewer's decision, date, reasons and the documents' hashes are recorded; a review that has expired, is dated after the scan or whose document is missing counts as not assessed. No model is involved.
