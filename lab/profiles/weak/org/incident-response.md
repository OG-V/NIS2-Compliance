# NordMSP — Incident Response Plan

Version 0.3 · Owner: IT · Last reviewed: 2023-02-14

## Purpose
Describe what to do when something goes wrong with our systems.

## Procedure
1. Whoever notices the problem tells the IT lead.
2. IT investigates and fixes the issue.
3. Customers are informed if needed.
