# Legal sources

Plain-text copies of the legal instruments, generated by `nis2scan fetch-sources` from
the official English HTML on EUR-Lex. They are the ground truth for quote verification.
Every extracted requirement records the SHA-256 of the file it came from, so if a source
changes, stale extractions show up.

| File | Instrument | Retrieved | SHA-256 |
|---|---|---|---|
| `cir-2024-2690-annex.txt` | Commission Implementing Regulation (EU) 2024/2690 (CELEX 32024R2690) | 2026-09-24 | `65ebc68b6cb3a942…` |
| `nis2-2022-2555.txt` | Directive (EU) 2022/2555 (CELEX 32022L2555) | 2026-09-24 | `8c20bd32b981f214…` |

Full URLs and hashes are in [`manifest.json`](manifest.json).

**Normalisation:** HTML tags are removed and whitespace is collapsed. A point marker
(`11.7.1.`, `(a)`) is joined with the text that follows it. The CIR file holds only the
Annex. No words are changed.

**Reuse:** © European Union, https://eur-lex.europa.eu. EUR-Lex permits reuse of these
documents provided the source is acknowledged. Only the official Journal version is
legally authentic.
